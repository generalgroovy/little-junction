How to route

Each cart carries a station symbol: ☀ Sun, ☾ Moon or ♧ Leaf. Step moves every cart one track and admits one waiting cart. Carts wait if the next junction is occupied.

Sun uses the upper branch; Leaf uses the lower. Both branches can reach Moon. Set several junctions before stepping. If the next step would send a cart to the wrong station, a warning appears. Undo lets you reroute a cart that has gone too far.

Auto step moves every 1.4 seconds. Pause, Step, Undo or leaving the tab stops it. A wrong delivery also pauses it. Start again keeps the same arrival order and can be undone.
